# Security Knowledge Base

A MkDocs-based collection of practical cybersecurity projects, models,
case studies, decision frameworks, and reusable templates.

The knowledge base explores how business risks and technical realities can
be translated into practical controls, clear documentation, and reviewable
evidence.

## Selected content

- **ISO/IEC 27001 control dependency modelling**
    -  Mapping how controls and management-system activities depend on one another and what weakens downstream when an upstream control is ineffective.
- **Trust boundary analysis**
    - Identifying where systems, owners, protocols, or data formats change and assessing the risks created at those boundaries.
- **Client cybersecurity discovery frameworks**
    - A structured framework for understanding a client’s business context, technology environment, security practices, risks, and priorities before proposing controls or services.
